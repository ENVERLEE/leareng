로컬 프론트엔드 개발 가이드

1. 간단한 HTTP 서버 실행

Python 사용 (가장 쉬움)

cd frontend
python3 -m http.server 3000

브라우저에서 http://localhost:3000 접속

Node.js 사용

cd frontend
npx http-server -p 3000

VS Code Live Server 확장 사용

VS Code에서 "Live Server" 확장 설치 후 우클릭 → "Open with Live Server"

2. Railway 백엔드 URL 설정

중요: 로컬에서 프론트엔드를 실행할 때는 Railway 백엔드 URL을 사용해야 합니다.

index.html 파일의 <head> 섹션에 다음을 추가하세요:

<script>
    // Railway 백엔드 URL 설정
    window.BACKEND_URL = 'https://your-backend.railway.app';
</script>

3. CORS 문제 해결

Railway 백엔드의 환경 변수에 다음을 추가하세요:

CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:8080,http://127.0.0.1:3000

4. 빠른 테스트

브라우저 콘솔(F12)에서 다음을 실행하여 연결 확인:

fetch('https://your-backend.railway.app/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email: 'test@test.com', password: 'test' })
})
.then(r => r.json())
.then(console.log)
.catch(console.error);

5. 개발 팁

  • 브라우저 개발자 도구(F12) → Console에서 API URL 확인
  • Network 탭에서 API 요청 상태 확인
  • 에러 발생 시 상세 로그 확인
